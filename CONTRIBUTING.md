# Contributing

- main always runs; never push to it directly.
- Branch per task, e.g. r2/reassignment-timer. Small commits, e.g. 'r2: add dedup table'.
- Pull Request needs 1 review (pair partner), within 24 h.
- git pull --rebase origin main daily.
- Protocol changes: open a GitHub Issue labelled 'protocol' for R1.
- Tag submissions phase1, phase2, phase3.
